# GameTest

Online co-op (1–4 players) twin-stick roguelite bullet-hell shooter with dark fantasy pixel art, made in Godot 4. Windows only, mouse + keyboard or gamepad.

**Playtesting?** Grab the latest zip from [Releases](https://github.com/Tristan2828/GameTest/releases/latest), unzip it, and run `GameTest.exe`. The included `README.txt` explains hosting, joining and controls.

## For developers
- `DESIGN.md`: game design, the source of truth
- `CLAUDE.md`: engine rules, project layout, and how to test, build and release
- `docs/PLAYTEST.md`: the human playtest checklist
