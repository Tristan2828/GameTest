# Medieval Survival

Online co-op (1–4 players) roguelite bullet-hell survivor (you move and dodge; your weapons fire by themselves) with dark fantasy pixel art, made in Godot 4 (working title: GameTest). Windows only, mouse + keyboard or gamepad.

**Playtesting?** Grab the latest zip from [Releases](https://github.com/Tristan2828/medieval-survival/releases/latest), unzip it, and run `MedievalSurvival.exe`. The included `README.txt` explains hosting, joining and controls.

## For developers
- `DESIGN.md`: game design, the source of truth
- `CLAUDE.md`: engine rules, project layout, and how to test, build and release
- `docs/PLAYTEST.md`: the human playtest checklist
- `docs/RELEASING.md`: publishing builds (GitHub Releases + Discord announcements)
- `docs/ART_BRIEF.md` / `docs/AUDIO_BRIEF.md` + `assets.yaml`: the art and audio files that replace the text sprites and synth
