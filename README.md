# Medieval Survival

Online co-op (1–4 players) roguelite bullet-hell survivor (you move and dodge; your weapons fire by themselves) with dark fantasy pixel art, made in Godot 4. The repository is still called GameTest (it was the working title). Windows only, mouse + keyboard or gamepad.

**Playtesting?** Grab the latest zip from [Releases](https://github.com/Tristan2828/GameTest/releases/latest), unzip it, and run `MedievalSurvival.exe` (called `GameTest.exe` up to v0.24.0). The included `README.txt` explains hosting, joining and controls.
