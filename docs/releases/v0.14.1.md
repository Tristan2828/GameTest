The game can now update itself.

### What's new
- **One-click updates.** The title screen checks for a newer version. When one is out you'll see "Version X is out!" and an **Update now** button: it downloads the new version, swaps it in and restarts the game. No more downloading zips by hand after this one.
- The version text on the title screen says **(latest version)** when you're up to date.

### What to test
- Nothing to do yet: the update button appears the next time a new version is released. When it does, press it and tell us if it worked, or if Windows or your antivirus complained.

Post bugs in **#bug-reports** (include the version from the bottom of the menu) and thoughts in **#feedback**.
