A small packaging update: the game now has its own icon, and the Windows warning is easier to get past.

### What's new
- **The game has an icon** (the hooded Wanderer) and shows its name and version under Properties > Details.
- **Fewer scary warnings.** Windows warns about new games that aren't signed by a big publisher. Before unzipping, right-click the zip > Properties > tick **Unblock** and the warning goes away. The README in the zip explains it, and it's updated for revives, hero names and Embers.
- Already playing? Just press **Update now** on the title screen: in-game updates never get the warning.

### What to test
- New players: did the Unblock tip work, or did Windows still warn you?
