**Everyone on v0.24.0 or older: download this one by hand** (the zip below). The GitHub page moved to a new name, and older versions' Update button can't follow it. From this version on, Update now works again. The exe is now called **MedievalSurvival.exe**; you can delete your old GameTest.exe.

### What's new
- **Hero unlocks:** everyone starts with Kael. Win a full run to unlock the next hero: Mortimer, then Morwen, then Vesper. In co-op a team win counts for everyone, and each player picks from their own unlocked heroes.
- **New hero sprites** for all four heroes.
- **Music** now plays from proper audio files (same songs).
- **Update button** is sturdier: it says when it can't check and offers Check again.
- **Hellfire Trail** is much more muted.
- **Fixed:** opened chests stayed on the screen for the host.

### What to test
